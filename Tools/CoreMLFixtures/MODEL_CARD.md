# Public arithmetic fixtures for spec 0004

These are repository-authored synthetic neural-network classifiers, distributed under the repository [MIT license](../../LICENSE). They contain no trained weights, external dataset, protected model/vocabulary, user text, or runtime download. Their purpose is to test the complete local Core ML adapter contract.

The three versioned adapters use different feature names, sequence lengths, input dtypes and optional-input layouts. A single affine layer computes three raw components from positional sums of token IDs/mask/type IDs. The probability fixture includes a Core ML softmax layer; the others produce logits. Their verified semantic mappings mean only `com.qualiakit.fixture.component0…2`, arbitrary components of this explicit arithmetic. Confidence is unavailable. The `en` capability selects this test contract and does not assert English language understanding.

**Intended use:** schema, asset, tokenizer, input, output, concurrency and cancellation integration tests. **Excluded use:** sentiment/narrative inference, heartbeat or product decisions, quality comparisons with trained models. No human subjects, training samples, learned class balance or production thresholds exist.

`generate.py` is the primary model definition. `reference.py` is a separate stdlib arithmetic oracle with manually specified content-token vectors. Each adapter has ten cases covering ASCII folding, all declared whitespace, preserved Unicode/combining marks, punctuation, unknown tokens, boundaries and truncation. Golden raw scores and mapped values are computed by the oracle, not recorded from the Swift implementation or Core ML. Tests compare actual Core ML raw outputs and complete runtime observations to them at absolute tolerance 1e-6. The stdlib verifier allows 1e-14 for Python/libm rounding differences while preserving exact token vectors and committed file checksums.

The manifest's single calibration/holdout process counts refer to the fixture verification runs with these analytical bounds; they are not a measured production calibration protocol. No latency, memory, energy, device-quality or training-tokenizer parity claim follows from this fixture. Physical-device performance and protected-current-model parity remain later work.

Normal CI needs only Swift/Core ML and Python stdlib:

```sh
python3 Tools/CoreMLFixtures/verify.py
swift test --package-path Packages/QualiaCoreML --filter CoreMLRuntimeTests
```

For generation/reproduction, use Python 3.11 on macOS and install the pinned packages in `requirements.lock` into a disposable virtual environment. Then run `python generate.py`; the default compares regenerated bytes with the committed artifacts without changing them. An intentional reviewed update uses `--write`, with a new contract/fixture version for any changed released artifact. The generator uses deterministic protobuf serialization. Source and vocabulary SHA-256 values, generator/environment identities, golden/corpus hashes and reference code identity are recorded in each manifest.

Compiled artifacts are not distributed. The precompiled-source test builds its local `.mlmodelc`, pins every file, records the source/compiler relationship and verifies missing, changed and extra file rejection. Runtime diagnostics report only redacted counts, identities and timings; fixture text is public and lives solely in the test corpus.

# Community code of conduct

Participation should be respectful and safe for contributors and users of all
backgrounds and abilities. Discuss observable behavior and technical tradeoffs.
Accept feedback, credit contributions and respect privacy and accessibility needs.

Harassment, threats, discriminatory abuse, sexual harassment, unwanted contact,
publication of private information and retaliation are not acceptable. This
applies to project issues, reviews, examples and spaces representing the project.

The repository maintainer moderates project spaces. Use GitHub's **Report content**
menu on the relevant content for confidential platform reporting; see
[GitHub abuse reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
If the maintainer is involved, report directly to GitHub rather than posting a
public accusation. Do not put private conduct reports in technical issue forms.

Maintainers may request a correction, remove content, restrict participation or
ban repeated or severe violations. Decisions should explain the behavior and
proportionate action while protecting reporter privacy. Affected participants
may request reconsideration through the original reporting channel. No private
report is published as an adoption metric.
